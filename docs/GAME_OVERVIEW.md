# Game Overview

## Product
Mobile-first Persian-language multiplayer strategy board game.

## Inspiration
Resource-production and settlement strategy inspired by classic hex-based board games.

## Platform
- Web / PWA
- portrait mobile first
- Phaser 4
- TypeScript

## Core Loop
1. Current player starts turn.
2. Roll two six-sided dice.
3. Produce resources from matching terrain numbers.
4. Player may trade.
5. Player may build roads, settlements, or upgrade settlements to cities.
6. Player may perform allowed special actions.
7. End turn.
8. Continue until victory condition is reached.
